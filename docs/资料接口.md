# 资料服务接口

资料源支持单段 HTTP Range，返回 Content-Range 和内容摘要 ETag。If-Match 可以限定本次范围读取的来源版本，版本不符返回 412，越界返回 416。该行为只负责传输，不替接收应用决定领域对象是否完整。

多个页面的提示可以同时指向一个资源；page-1 最终不引用 logo，page-2 引用，cancelled 产生 503。资源原件的存在与某个页面的正式引用并非一件事。

现有传输适配器将 1xx 与最终响应按实际发生顺序记成 exchange 事件；这是本地接口而非把 103 当普通正文。/pages/live 也会发送真实 103，供选择原生 HTTP 客户端时核对。资源字节为本地占位素材，采集程序不需要图片解码。

本地服务的资料入口为 `/exchange/page-1`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

采集核对的补充入口：`/exchange/slow` 提示并采用延迟 300ms 的 `/assets/photo-slow`，用于观察并发共享与取消；`/exchange/external` 提示后跳转到来源之外的地址，用于核对边界；`/exchange/broken` 提示并采用不存在的 `/assets/missing`，用于核对未完成原因。采集端把 103 提示当暂定工作，正式资料以终态事件真正采用的资源为准。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。
